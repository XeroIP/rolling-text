# Handoff Notes

Scratch space for handing off in-progress work between sessions or tools
(Claude Code, Codex, or a human). Not a running log — overwrite it at the
end of a session rather than appending, and clear it out once the work
lands on `main`.

For durable project context, use `CLAUDE.md` (and `AGENTS.md`, which
points to it) instead — this file is for what's true right now, not
standing instructions.
